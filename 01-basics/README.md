## Key Ideas

- A variable is a name that refers to an object.
- Every object has a type, such as `int`, `float`, `str`, `bool`, `list`, or `dict`.
- `id(x)` helps you inspect whether two names refer to the same object.
- Clear names make code easier to read than short names.

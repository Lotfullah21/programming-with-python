# Palindrome

A palindrome reads the same forward and backward after normalization.

Examples:

- `madam`
- `level`
- `A man a plan a canal Panama` if spaces and case are ignored

Run the example:

```bash
python3 09-strings/06-palindrome/palindrome.py
```

The program removes spaces, converts the input to lowercase, and compares characters from both ends moving toward the center.

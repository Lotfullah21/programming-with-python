# List Practice Examples

These examples were consolidated from the old top-level `Lists` folder. They are kept here as extra practice after the main list lessons.

## Files

| File | Practice goal |
| --- | --- |
| `lists.py` | Create and inspect lists |
| `iteration_over_lists.py` | Loop through list values |
| `list_methods.py` | Use common list methods |
| `list_conversion.py` | Convert between lists and other types |
| `aliasing.py` | See what happens when two names reference the same list |
| `duplicates.py` | Work with repeated values |
| `higher_order_programming.py` | Use functions with list processing |

## Study Prompt

Before running each file, predict what will print. After running it, change one list value and explain why the output changed.

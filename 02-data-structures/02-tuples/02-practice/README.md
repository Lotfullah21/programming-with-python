# Tuple Practice Examples

These examples were consolidated from the old top-level `Tuples` folder.

## Files

| File | Practice goal |
| --- | --- |
| `tuples.py` | Create tuples, index them, and compare them with lists |
| `function.py` | Return and unpack tuple values from a function |
| `unique.py` | Use tuples while working with unique values |

Tuples are ordered like lists, but immutable. If you need to change the collection later, use a list instead.

# Tuples

A tuple is an ordered sequence of values. Tuples are immutable, so their elements cannot be changed after creation.

```python
point = (3, 4)
print(point[0])  # 3
```

## When To Use A Tuple

- Use a tuple for fixed records, such as coordinates: `(x, y)`.
- Use a tuple when returning multiple values from a function.
- Use a list instead when the collection should change.

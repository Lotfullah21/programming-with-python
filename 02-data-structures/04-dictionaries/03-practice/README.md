# Dictionary Practice Examples

These examples were consolidated from the old top-level `Dictionaries` folder.

## Files

| File | Practice goal |
| --- | --- |
| `dictionary.py` | Create dictionaries and access values by key |
| `dictionary_comprehension.py` | Build dictionaries with comprehensions |

A dictionary connects a key to a value:

```python
student = {"name": "Ahmad", "age": 24}
print(student["name"])  # Ahmad
```

Keys must be unique and immutable, such as strings, numbers, booleans, or tuples.
